# 第一阶段落地记录

## 环境与边界

- Research Agent 使用独立项目和独立容器，避免与其他业务服务耦合。
- 百炼密钥只从运行时环境变量 `BAILIAN_API_KEY` 注入，不写入代码、镜像或版本控制。
- 模型端点和模型名可由环境变量覆盖。
- n8n 固定版本并使用固定工作流 ID 自动导入。
- 服务默认只绑定主机回环地址。

## 决策

- n8n 负责定时、可视化编排和执行记录。
- Research Agent 负责采集、确定性预筛、模型批处理和文件生成。
- 百炼评分每批最多 6 篇，并要求 JSON Object 输出；单批失败只降级该批。
- 第一阶段使用 Markdown/JSON 输出，第二阶段再加入持久化数据库与外部信号。

## 验收标准

- 单元测试覆盖 arXiv Atom 解析和 RAG/Agent 主题初筛。
- 使用运行时密钥完成真实模型调用并生成 Markdown/JSON。
- n8n 与 Agent 容器健康，工作流已导入并激活。
- 模型故障时明确标记降级，不把规则结果伪装成模型结论。
